Install Duck

This installer places Duck.vst3 in your VST3 plug-ins folder for use in Ableton Live and other hosts.

Install location: The default destination installs for all users at /Library/Audio/Plug-Ins/VST3. Click Change Install Location… to choose your home folder instead (~/Library/Audio/Plug-Ins/VST3) if you do not have an administrator password.

Click Continue, accept the license, then Install.
